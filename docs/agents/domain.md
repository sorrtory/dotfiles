# Domain docs

This is a single-context repository.

The canonical project documents are listed in `AGENTS.md`. Read them before architectural work and reference them instead of duplicating their content in specs or tickets.

Use the vocabulary established in `CONTEXT.md`. If a required concept is missing or ambiguous, note it for `/domain-modeling`.

Read relevant ADRs under `docs/adr/` when that directory exists. Create an ADR only for a hard-to-reverse decision. If proposed work contradicts an ADR, identify the conflict explicitly rather than silently overriding it.
