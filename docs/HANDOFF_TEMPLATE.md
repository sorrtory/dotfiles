# Session Handoff Template

Use this only when stopping mid-task. Do not duplicate stable project documentation here; point to it.

## Current objective

Describe the one task currently in progress.

## Read first

- `AGENTS.md`
- `CONTEXT.md`
- `docs/DECISIONS.md`
- relevant `.scratch/<effort>/map.md` and `spec.md`, when an effort exists

## What changed this session

List only concrete changes already made.

## Current state

State what works, what remains incomplete, and any legacy path still active.

## Next action

Give the smallest next executable step.

## Blockers / uncertainties

Record only unresolved questions that materially affect implementation.

## Verification performed

Record builds/tests/manual checks already completed so the next agent does not repeat them unnecessarily.

## Security

Do not include secret values, private keys, WireGuard private material, KeePassXC contents, session tokens, or decrypted SOPS data in this handoff.
